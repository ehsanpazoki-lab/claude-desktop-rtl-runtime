# v0.1.0-beta

First public beta of **Claude Desktop RTL Runtime + Vazirmatn**.

- no app.asar patching
- no Administrator requirement
- no MSIX re-signing
- upstream RTL engine pinned to `ab938536096145fb797f2f6cdbc7bb8c1a008b3e`
- Vazirmatn runtime font support
- live runtime restore via the upstream cleanup hook
- one manual Main Process Debugger step per Claude session

The project is unofficial and not affiliated with Anthropic.
