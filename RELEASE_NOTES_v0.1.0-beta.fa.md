# v0.1.0-beta

اولین Beta عمومی **Claude Desktop RTL Runtime + Vazirmatn**.

ویژگی‌ها:

- بدون Patch کردن `app.asar`
- بدون Administrator
- بدون MSIX re-signing
- upstream pinشده روی commit تست‌شده
- Smart RTL از Claude RTL Companion
- Vazirmatn runtime
- Disable/Restore زنده در صورت فعال بودن Main Process Debugger
- نسخه Portable و Windows Installer

این پروژه غیررسمی است و وابسته به Anthropic نیست.
