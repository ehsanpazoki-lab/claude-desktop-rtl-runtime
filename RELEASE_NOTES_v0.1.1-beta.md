# v0.1.1-beta

Installer UX update for Claude Desktop RTL Runtime + Vazirmatn.

- Adds an optional `Create a desktop shortcut` task, unchecked by default.
- Keeps the main launcher on Desktop only when the user explicitly selects it.
- Makes installer version/output naming derive cleanly from the Git tag.
- Makes installer release-note selection tag-aware.

Runtime RTL behavior is unchanged from v0.1.0-beta.
